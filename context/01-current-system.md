# The system being replaced

The Awqaf (Islamic endowments) office of **15 May City, Egypt** assigns preachers (خطباء,
_khatibs_) to mosques for Friday sermons (خطبة الجمعة). Today they do this in a single
Google Sheet. This document is a factual audit of that sheet, produced by reading the
exported `.xlsx` cell by cell. Everything here is verified, not assumed.

## Scale

| Thing | Count |
| --- | --- |
| Mosques | 85 |
| Khatibs (real names) | 127 |
| Friday/sermon columns currently in the sheet | ~51 |

## Sheet structure

Five tabs. Two carry data, one is machinery, two are dead.

### `المساجد` (mosques) — the primary matrix

A wide grid. One row per mosque, one **column per Friday**.

- `A` = mosque name (`النور المحمدي`)
- `B` = neighbourhood, called _mujawra_ (`مجاورة 1`). Some are named zones instead
  (`الإسكان العائلي`, `120 فدان`, `المنطقة الصناعية`, `دار مصر`).
- `C` … `BA` = one column per sermon slot. Each cell holds a khatib's **name as free text**,
  picked from a dropdown.

Column headers are prose, not dates: `الخطبة الاولي`, `الجمعه الثانية`, `الاولي من شوال`
(first Friday of Shawwal — a religious-calendar event, not a fixed Gregorian date).

### `الخطباء` (khatibs) — the reverse view

One row per khatib.

- `A` = name
- `B` = labelled `رقم الهاتف` (phone) but actually contains a `COUNTIF` formula. **All phone
  numbers have been destroyed.** They will be re-entered by hand.
- `C` = labelled `ملاحظات` (notes), completely empty
- `D` … `BB` = `=COUNTIF('المساجد'!C:C, $A2)` — one per sermon column. Result `1` means this
  khatib is already booked that Friday, `0` means free.
- `BE` onward = the mosques this khatib is assigned to, headed `الخطبة 1`, `الخطبة 2` …
  Generated by `ARRAYFORMULA` + `FILTER`.

### `Array` — the dropdown engine

~11,930 rows of helper formulas.

- Column `A` = `=IF('المساجد'!A:A="", "", 'المساجد'!A:A & " " & 'المساجد'!B:B)` — produces
  `"النور المحمدي مجاورة 1"`, the label used in the khatib-side dropdowns.
- Columns `E:BV` = per sermon slot, the khatibs **not yet booked** that Friday. This is what
  makes the mosque-side dropdown show only available people. **This double-booking
  prevention is the single most valuable behaviour of the current system and must be
  preserved.**

### `Sheet1`, `Copy of Sheet1` — dead

`Sheet1` holds one horizontal row of 83 `mosque + mujawra` strings. `Copy of Sheet1` is
empty. Both are leftovers.

## Verified defects

These are the reasons for the rewrite. Each was confirmed by inspecting cells.

1. **A column is added every single Friday.** Confirmed by the client. After a year that is
   52 columns; after three years, 156. Every new column needs its data-validation wired by
   hand, and that wiring is already broken in places.

2. **Formulas do not survive export.** The file is a Google Sheets export. Every
   `ARRAYFORMULA`/`FILTER` became `__xludf.DUMMYFUNCTION` and is dead in Excel. The sheet
   only works inside Google Sheets.

3. **Numbers sitting in name cells.** 60+ cells inside the assignment matrix contain a bare
   integer instead of a khatib name — `112`, `215`, `226`, `240`, `242`, `287`, `453` and
   others. Those mosques silently have **no** preacher for that Friday while appearing filled.

4. **Names assigned but not on the roster.** Five names appear in the matrix yet do not exist
   in the `الخطباء` list:

   | Name | Occurrences |
   | --- | --- |
   | `عاطف ابو الفضل` | 16 |
   | `عبدالسلام محمود بسيوني` | 4 |
   | `أسامة السيد` | 3 |
   | `اشرف` | 2 (truncation of `اشرف عبد القادر عبدالكريم`) |
   | `محمد حسن فنتاوي` | 1 |

5. **70 of 127 names carry trailing whitespace.** `COUNTIF` compares strings exactly, so a
   stray space silently breaks the availability calculation. There are also outright
   misspellings: `محسن محمد أحمدج`, `هشلم محمد صادق`.

6. **No identifiers anywhere.** Mosques and khatibs are joined by their display text. Fixing
   a typo in a name breaks every assignment that referenced it.

7. **~870 filler rows** containing `0` pad the khatib sheet to 1001 rows. Combined with the
   12k-row `Array` tab, the file is slow.

8. **Inconsistent validation ranges.** Different cells point at `Array!$A$2:$A11960`,
   `$A$2:$A5521`, `$A$2:$A1000` — evidence of manual copy-paste drift.

9. **No operational record.** Nothing tracks absences, substitutions, who changed what, or
   when.

## Mosques with a permanent khatib

Several mosques show the same name in every column — they have a de-facto permanent
preacher. Examples verified in the data:

| Mosque | Permanent khatib |
| --- | --- |
| `النور المحمدي` (مجاورة 1) | `محمد أحمد فريد` |
| `الفردوس` (مجاورة 3) | `هاني سويد` |
| `الكاظم` (مجاورة 2) | `احمد فاروق عبدالحليم` |

This pattern is why the new system gets an explicit "permanent khatib" field on the mosque.
